
# Практическая работа №3

## Автоматизация резервного копирования

**Студент:** Хахазов Руслан Нуридинович

**Вариант:** 17

## Файлы проекта

- make_test_data.py — создание тестовых данных.
- backup.py — создание резервных копий, ротация, проверка и восстановление.
- rpo_rto.md — расчёт показателей RPO и RTO.

## Запуск

Создание тестовых данных:

```bash
python3 make_test_data.py
```

Создание резервной копии:

```bash
python3 backup.py
```

## Используемые технологии

- Python 3
- SHA-256
- JSON
- TAR.GZ
- pathlib
- shutil
- tarfile

## Результат

Создаются резервные копии данных трёх отделов:
insurance, claims и buh.

Система хранит последние 8 резервных копий,
проверяет целостность и поддерживает восстановление данных.
